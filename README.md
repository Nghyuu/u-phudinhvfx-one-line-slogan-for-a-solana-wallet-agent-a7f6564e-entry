## Entry

`main.ts` writes a single-line slogan (at most 20 words, 1–140 characters)
to `entry.txt` in `$MAKEFUN_OUTPUT_DIR`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
